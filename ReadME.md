# AWS Cloud Security Posture Assessment Tool

## Overview

CloudGuard is a Python-based Cloud Security Posture Assessment (CSPM) tool that analyzes AWS environments for security misconfigurations and provides risk-based findings.

The goal is to automate cloud security checks and help identify insecure AWS configurations.

---

## Planned Features

- IAM security checks
- S3 bucket security analysis
- EC2 configuration assessment
- Security group review
- CloudTrail monitoring checks
- Security risk scoring
- HTML/JSON security reports

---

## Tech Stack

- Python
- AWS SDK (boto3)
- Jinja2
- Git/GitHub
